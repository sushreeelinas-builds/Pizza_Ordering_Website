# 🍕 Pizza Ordering Website

A modern and responsive **Pizza Ordering Website** built to provide users with a simple and convenient online pizza-ordering experience. The project focuses on an attractive user interface, responsive design, and smooth interactions using HTML, Tailwind CSS, and JavaScript.

## 🌐 Live Demo

[View Live Website](https://pizzaorderingwebsite-virid.vercel.app/)

## 🚀 Features

- **Responsive Design** – Works across desktop, tablet, and mobile devices.
- **Modern UI** – Clean and attractive pizza-themed interface.
- **Interactive Elements** – JavaScript-powered user interactions.
- **Pizza Showcase** – Display pizza items with their details.
- **User-Friendly Experience** – Simple and intuitive navigation.

## 🛠️ Tech Stack

- **HTML5** – Website structure.
- **Tailwind CSS** – Responsive styling and UI design.
- **JavaScript** – Interactive functionality.
- **Vercel** – Deployment and hosting.
